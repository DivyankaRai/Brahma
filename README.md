# Fastor Food Ordering App

Live URL:- https://brahma-lyart.vercel.app/

## Features

- Sign up using a mobile number.
- OTP verification page.
- Home page with best-selling and popular food items.
- Food details page with portion selection.
- Increase and decrease food quantity.
- Automatic total price calculation.
- Add to Cart button with confirmation feedback.
- Responsive layout styled with Bootstrap.

## Tech Stack

- React
- JavaScript
- React Bootstrap
- Bootstrap
- React Router DOM
- CSS
- Vite

## How It Works

1. Enter a mobile number on the sign-up page.
2. Navigate to the OTP page for verification.
3. Browse available food items on the home page.
4. Open a food item to view its details.
5. Select a portion size and adjust the quantity.
6. View the updated total price and click **Add to Cart**.
